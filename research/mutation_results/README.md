# Prespecified workflow fault-detection experiment

The unmodified baseline passed 111 cases: 103 HTTP/PostgreSQL integration cases and 8 service cases. Each of the ten specified faults was then applied separately to an isolated source copy, using the same 103 integration assertions.

| ID | Fault | Failures in matrix (90) | Failures in dedicated cases (13) | Outcome |
|---|---|---:|---:|---|
| M01 | Include the withdrawal endpoint | 0 | 3 | detected |
| M02 | Exclude the treatment start | 0 | 2 | detected |
| M03 | Include the administration endpoint | 0 | 2 | detected |
| M04 | Require every active treatment to be in administration | 5 | 1 | detected |
| M05 | Retain expired treatment state | 4 | 3 | detected |
| M06 | Remove the wintering harvest guard | 5 | 0 | detected |
| M07 | Throw after recording business rejection | 22 | 4 | detected |
| M08 | Remove explicit per-hive write lock | 0 | 1 | detected |
| M09 | Keep nanoseconds in harvest event time | 0 | 1 | detected |
| M10 | Omit transition event association | 30 | 1 | detected |

The matrix detected 5/10 specified faults. The complete integration suite detected 10/10. This is descriptive attribution within the selected fault set; no test assertions were added or changed after observing outcomes.

`manifest.json` and M01–M10.patch define all planned faults. M01–M10.json retain every executed test identity and outcome; `summary.json` also retains non-detection categories. `test_group_attribution.csv` is generated by `research/summarize_workflow_mutations.py`. The manually reviewed `independent_failure_review.csv` connects observed failures to specific assertions and documents interpretation limits.

M07 is detected through HTTP 500 instead of the expected business rejection 409; those failing assertions precede the subsequent audit-row assertions. M08 removes the lock annotation used by both the command and the controlling transaction in its test. Its observable missing lock wait supports a protocol violation, not an independently observed incorrect harvest decision under concurrency. These results are not a correctness proof or an exhaustive assessment of mutation operators or interleavings.

Raw logs and source copies remain in the local work directory and are not part of this publication artifact. Patch files use LF line endings; their byte SHA-256 values match the manifest. See ../README.md for reproduction.
